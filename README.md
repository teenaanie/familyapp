# Family Helper

A voice-first family app (installable PWA for iPhone): reminders, vegetable bill checker, staff attendance & pay, and monthly payments.

See [docs/PLAN.md](docs/PLAN.md) for the full plan and build phases.

## Run locally

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
